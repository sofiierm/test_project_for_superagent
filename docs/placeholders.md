## Что уже работает без участия заказчика

- Обе темы оформления, переключатель, сохранение выбора, системная тема по умолчанию.
- Адаптив на контрольных разрешениях ТЗ §7.1 (320–1920), без горизонтальной прокрутки.
- Валидация формы на клиенте и сервере по одним правилам, honeypot, ограничение частоты.
- SEO-минимум: title/description, canonical, OG/Twitter, `sitemap.xml`, `robots.txt`, микроразметка Organization / LocalBusiness / FAQPage / WebSite.
- Cookie-баннер с отказом, события аналитики в `window.dataLayer` до подключения счётчика.
- Лайтбокс портфолио, аккордеон FAQ, мобильное меню, ловушка фокуса, `prefers-reduced-motion`.

## Что нельзя закрыть без заказчика

1. Реальные контакты, реквизиты и цифры — сейчас демонстрационные.
2. Фотографии объектов — заменяются съёмкой заказчика; текущие подобраны по описаниям и лицензиям.
3. Текст политики конфиденциальности — нужна юридическая проверка.
4. Приём заявок — нужен URL вебхука (CRM, Telegram-бот или почтовый сервис).
5. Аналитика — нужен выбор провайдера и номер счётчика.
6. Домен и хостинг — нужны доступы для деплоя и проверки Core Web Vitals на продакшене.
